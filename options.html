Okkazeo × BGG

Affiche la note BoardGameGeek à côté des jeux vendus sur Okkazeo.

1. Jeton d'accès BGG

BGG demande un jeton pour utiliser son API (gratuit pour un usage non commercial) :

  1. Connecte-toi sur boardgamegeek.com.
  2. Va sur boardgamegeek.com/applications et enregistre une application (usage personnel, non commercial). La validation par BGG peut prendre quelques jours.
  3. Une fois l'application validée, crée un jeton (« token ») et colle-le ci-dessous.

2. Accès à boardgamegeek.com

L'extension doit pouvoir contacter boardgamegeek.com. Firefox peut demander de l'autoriser.

Cache

Les notes sont gardées 14 jours, les jeux introuvables 3 jours, pour limiter les appels à BGG.
